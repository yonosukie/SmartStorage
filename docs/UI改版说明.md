# 物品页面 UI 改版

## 设计与范围

按已确认的三页设计稿落实暖白背景、深青绿主色、白色圆角卡片、统一字号与间距，同时提供对应深色配色。

- 物品列表默认使用横向照片卡片，展示分类、存放路径、汇总数量及到期状态。提供分类快捷筛选、列表/网格切换；原有详细筛选、排序、导出保留。
- 详情页增加照片区、分类标记、多位置库存卡片、物品信息及备注。底部固定补货和编辑操作；批次管理、消耗、移动、盘点、历史流水、撤销和归档保持可用。
- 新增/编辑页突出照片、基本信息、存放位置、数量和备注。价格、日期、标签折叠到“更多信息”；识别和抠图配置折叠到“图片处理设置”。保存按钮固定，输入错误显示在按钮上方，返回仍会确认是否放弃。
- 底部导航按首页、物品、空间、我的排列。新增使用加号按钮。
- 共享卡片使首页同步使用横向样式，空间页仍使用适合网格的紧凑卡片。共享主题与表单卡片同步影响其他页面的颜色、圆角与字体。

## 与设计稿的适配

- 使用用户真实照片；无图、加载中及图片不可读时显示占位图标。
- 数据模型没有品牌/型号字段，详情展示实际存在的库存、成本和添加日期。
- 支持一个物品存放在多个位置，各位置显示数量，保留批次维度操作。
- 保留此前取消计量单位展示的要求，不恢复“件/瓶”等单位。
- 新物品默认可保存在“待归位”，无需强制先建立空间。
- 不改动数据库结构和库存计算规则；继续保留拍照、AI 填表、同名补货及抠图流程。

## 验证

运行 scripts/Build.ps1 -Mirror：核心测试、Android 单元及 Compose 组件测试、Android Lint、调试 APK 构建。

新增回归覆盖数量加减下限/上限和手动输入、折叠字段后保留草稿、多位置卡片数量汇总及点击跳转。

当前没有连接 Android 设备，尚未进行真机视觉验收。建议安装后验证：

1. 列表搜索、分类、筛选、清空、网格切换和导出。
2. 有照片/无照片、超长名称、多存放位置和到期状态。
3. 新增、同名补货、编辑、折叠选填项、返回确认和输入法弹出时保存按钮。
4. 详情补货、消耗、移动、盘点、批次日期、记录撤销。
5. 小屏、大字体及深色模式下的滚动、换行与按钮触达。
