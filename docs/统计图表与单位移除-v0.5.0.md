# v0.5.0 统计图表与单位移除

## 统计展示

统计页只保留范围/维度选择和图表卡片，取消独立数字卡片、文字汇总、重复分组明细列表。覆盖分类/房间/标签的价值、库存数量、物品种类，以及价格填写率、有效期、贵重物品数量与价值、拥有时间与价值、过期批次与价值、历史过期损耗。

总计、分组数值、比例在图表内部和图例展示。空数据以灰色空环和 0 显示，不伪造数据。数量图不再错误标成批次数量；物品种类和批次分别去重统计。

分类/房间/标签、有效期和过期分类图可选图例后查看明细。合并的“其他”分组不提供错误的单项筛选。历史损耗按月份顺序展示，排除已撤销操作与缺价金额。标签存在重叠，卡片说明其累计值不能视为库存总值。

## 删除计量单位

移除录入/编辑的计量单位选择，列表、物品详情、库存操作、流水和同名补货提示不再显示单位，Excel 的物品汇总及批次位置表删除单位列。库存数量、单价、总价值和出入库规则保留。

AI 不再请求单位，自动填写不能修改隐藏的旧单位。旧数据库和备份中的 unit 字段仅作兼容保留，防止历史数据和旧备份损坏；不在产品界面或 Excel 中暴露。新增物品使用兼容默认值，不需要用户填写。

v0.4.0 的 OpenRouter 识别、remove.bg 抠图和密钥保存功能保留。
