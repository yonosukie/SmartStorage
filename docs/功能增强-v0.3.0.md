# v0.3.0 功能增强

## 矩形容器

在房间布局中选择容器后，宽度和高度可分别设置为 1–10 格。支持细长柜子、横向抽屉等矩形，继续与十格参考线对齐。变大后若超出边界会自动平移到房间内，支持撤销、重做及保存。

## remove.bg 自动抠图

在“我的”或物品录入页的“自动抠图”卡片中首次填写 API Key。密钥使用 Android Keystore AES-GCM 加密，仅保存在应用私有配置中，不预置到 APK，不写入源码、Git 或物品备份。清除配置会关闭自动抠图。

保存密钥后默认开启自动抠图。相册选择和系统相机拍照共用导入流程：先保存本地原图，再向 remove.bg 发送照片。成功结果为透明 PNG，录入前可切换原图/抠图；失败保留原图并展示原因，可手动重试。物品名称分类识别、云备份仍未接入。

调用固定 HTTPS 接口，使用 `image_file` 上传、`size=preview` 和 `format=png`，不跟随重定向，不记录密钥或响应正文。连接/读取设置超时，限制返回体大小并校验 PNG。不会自动重试付费请求；账户额度与网络状态影响实际可用性。接口来源：[remove.bg 官方 API 文档](https://www.remove.bg/api)。

透明图片导入、应用内保存和备份恢复均支持 PNG。新版本可以恢复旧 JPG 备份；含 PNG 的新备份需 v0.3.0 或更新版本恢复。密钥不会随物品备份迁移，新设备需重新输入。

## 级联位置选择

录入、补货、移动和位置筛选共用级联弹窗。逐级选择房子、房间、容器、分层或内部子容器，展示完整路径，可返回上一级；点击“选择此位置”才提交，取消不改变原选择。物品不能直接存入房子，筛选允许选择整栋房子及全部位置。

## 统计图表

- 分类/房间价值环形图，点击图例查看对应金额。
- 标签价值条形图；标签可重叠，不能将标签总值理解为库存总价值。
- 库存有效期环形图：已过期、即将到期、有效期内、未设置日期；按唯一在库批次计算。
- 拥有时间条形图，按仍在库的唯一购买批次计算。
- 前六组之外合并为“其他”，保留原有明细列表。金额缺失不计入价值，空数据提供说明，不绘制虚假数值。

## 验证范围

使用主机 Robolectric 测试级联点击和抠图 HTTP 合同，服务返回由本地测试替身提供，不发送用户照片，不消耗账户额度。真实 remove.bg 请求、Android Keystore 真机保存以及实际触控/视觉效果需要设备验收。最终 50 项测试通过、Lint 无问题，详见 [验证记录](验证记录-v0.3.0.md)。

## 服务维护

remove.bg 官方文档公告自 2026-12-01 起转向 Leonardo.Ai，届时需要适配新服务。当前实现按仍在使用的 remove.bg 接口接入，并集中封装在 RemoveBgClient，便于后续迁移。[官方公告与 API 文档](https://www.remove.bg/api)。
