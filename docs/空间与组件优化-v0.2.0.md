# 空间与组件优化 v0.2.0

本轮按用户确认采用“按层管理物品”。AI 识别和云备份继续只保留接口。

## 浏览与卡片

房子 → 房间 → 容器 → 分层逐级浏览，使用自适应卡片网格。顶部提供路径导航、空间概况和主要操作。卡片显示名称、类型、物品种类数；容器显示层数。物品卡片显示照片、名称、库存、完整位置和最早到期日期。

房间布局中的容器点击后进入对应容器页面，可继续查看分层。长按物品拖向同屏的容器或层卡片，松手后选择移动数量；跨层移动也可从详情的位置选择器操作。

## 容器层数

- 层数支持 0–20，0 表示不分层。第 1 层在最上方，依次向下。
- 每层具有独立 ID、层号、可编辑名称，可直接存放物品和子容器。
- 已有直接存放于容器的物品保持原位置，用户按需要移入具体层。
- 减少层数前，被移除的层及其后代必须没有在库物品，且没有未归档子容器。
- 缩减采用归档保留层 ID，流水和历史库存引用保留；重新增加层数时恢复原 ID。
- 层参与完整位置路径、搜索、筛选、统计和备份；房间和容器范围自然包含下属分层。

## 房间参考网格

画布采用 10 × 10 参考网格，坐标与宽高按同样的 0.1 比例量化。拖动从起点累计位移后吸附，避免每次小位移被取整导致拖动不灵敏。缩放、旋转使用同一规则，并将矩形限制在房间范围内。

取消原有容器外侧留白，使矩形边缘与参考线对应。旧版本非整格布局打开时按新网格显示，保存后写入新坐标。布局为相对位置示意，不代表真实尺寸。

## 输入组件

沿用项目现有的开源 Jetpack Compose Material 3：日期使用 DatePickerDialog，单选使用可搜索的单选对话框和 RadioButton。录入表单按基本信息、库存与存放、标签与备注分组。

购买日期不能晚于到期日期；有效期范围筛选同样限制起止顺序。日期支持清除，继续允许未知日期为空。日期与日历毫秒转换统一使用 UTC，避免时区造成日期偏移。

## 数据兼容

库存数据版本升级到 2；继续读取版本 1 备份，恢复后升级。Place 的层号为可空字段，旧记录默认无层号。层数据保存在现有 Room 位置表的 JSON payload 中，表结构无变化，不清空旧数据库。

## 验收要点

检查卡片在窄屏、深色模式、大字体下的可读性；验证长按拖拽、网格四边对齐、日期弹窗、跨层移动和重启后位置持久化。主机自动化结果另见本轮验证记录，触控体验仍需 Android 设备验收。
