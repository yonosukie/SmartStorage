# 统计体验优化 v0.6.0

统计页聚焦三个日常问题：哪些物品快到期、哪些分类囤得多、物品放在哪里。

- 到期提醒：分段状态条搭配四个状态图例，优先展示已过期和即将到期。点击非空状态打开清单。同一批次分放多个位置仅统计一次。
- 分类分布：数量采用可横向滑动的柱状图，价值采用环形图，通过数量／价值切换。柱形可直接打开分类清单；环形图选择图例后查看明细。缺失价格不计入价值。
- 房间收纳分布：横向条形图按数量排序，显示完整位置路径，点击进入对应清单。使用位置 ID 跳转，避免不同房子同名房间混淆。
- 所有图表跟随房子范围；零库存和归档物品继续遵循现有筛选规则。

移除独立的种类数量、价格填写率、贵重物品占比、重复价值、拥有时间、过期分类和历史损耗图表。原始库存和操作记录保留，物品列表仍支持贵重、有效期等筛选。计量单位继续不展示。
